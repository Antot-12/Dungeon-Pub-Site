# Dungeon Pub - Website

This is the official website for the Dungeon Pub, a fantasy-themed pub for gamers and adventurers. This project was built with Next.js and Firebase Studio.

## ✨ Features

*   **Homepage:** A welcoming page showcasing what the pub offers, including features, opening hours, and location.
*   **Menu:** A full, interactive menu with multiple language support.
*   **Events:** A section directing users to Facebook for the latest event information.
*   **Gallery:** A photo gallery to display moments from the pub.
*   **About Page:** The story and mission of the Dungeon Pub.
*   **Internationalization (i18n):** The site supports multiple languages (Slovak, English, Czech, etc.).
*   **Responsive Design:** Fully responsive and works on all devices.

## 🚀 Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **UI Components:** [ShadCN/UI](https://ui.shadcn.com/)
*   **Language Support:** React Context for internationalization.

## Getting Started

### Prerequisites

*   Node.js (v18 or later)
*   npm or yarn

### Installation

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
