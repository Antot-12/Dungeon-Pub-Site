# **App Name**: Dungeon Hub

## Core Features:

- Multilingual Support: Allows users to switch the website's language between English, Slovak, Czech, Ukrainian, Polish, and Hungarian.
- About Us Section: Displays information about Dungeon Pub, its history, and the community it fosters. Users can read about the events and activities available.
- Photo Albums: Displays photo albums from past events and gatherings.
- Menu List: Shows the drink menu including categories like beer, cocktails, shots, whiskey, etc.
- Cool Site Augmentation: Use AI tool to find cool things about bars and RPG and fantasy events, incorporate at least one into a rewrite of existing pages or the creation of new ones

## Style Guidelines:

- Primary color: #20242f, a dark background color.
- Background color: #1d1d1d, an even darker desaturated background.
- Accent color: #e84855, a vibrant color to highlight key interactive elements.
- Headline font: 'Belleza' sans-serif, suitable for headlines, for a design and arts feel. Body Font: 'Alegreya' for main website paragraphs
- Use fantasy and gaming-themed icons to enhance the site's visual appeal.
- The layout features an easy-to-navigate structure, focusing on visual content and seamless access to information.
- Subtle transitions when switching languages and browsing content.
